## **Build**

Clone the repository:

```bash
git clone https://github.com/BorschtOverflow/CoffeeCrypt ; cd CoffeeCrypt
```

Build from source:

```bash
./gradlew build
```

## **Documentation**

Generate from source:

```bash
./gradlew javadoc
```

Or go to [GitHub Pages](https://borschtoverflow.github.io/CoffeeCrypt)
